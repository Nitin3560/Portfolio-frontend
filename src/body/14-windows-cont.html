You found the room with no door.

Everything on this desktop — the window manager, the wallpaper, the tape deck, the maze, this room — is one HTML file served from a bucket. No framework, no bundler at runtime, no backend, no analytics, nothing phoning home. The whole thing is about 210 KB, which is smaller than the hero image on most portfolio sites.

How it is actually built

  • Windows — drag, eight-edge resize, maximise, minimise, z-order and a taskbar, written by hand. No library.
  • Wallpaper — canvas 2d, drawn from a seeded PRNG so the city is the same city on every load. The neon signs flicker on a timer, not a frame loop, so an idle tab schedules nothing.
  • Tape deck — Web Audio. In synth mode there are no files at all: FM piano, a filtered saw bass and noise drums, sequenced live. The spools wind at the right speed because the radius is √(hub² + fraction · (full² − hub²)).
  • Pac-Man — tile movement with sub-tile interpolation, the four original ghost targeting rules, scatter/chase waves.
  • Discipline — every animation loop is gated on being visible and in front. An untouched desktop costs zero frames.
